# Mini-Project 2026 - Modelling of Dynamical Systems - 3D Printer 

This is the codebase used for the miniproject exam of Modelling of Dynamical systems. 

## AI STATEMENT
The preparation of this assignment was completed in accordance with the Use of AI statement guidelines of the Faculty
of Mechanical Engineering (ME) at TU Delft. In particular, an AI assistant (Gemini) was utilized for the following
purposes: 

• Conducting general syntax and grammar checks to improve the readability of the report. 

• Assisting with LaTeX formatting.

• Acting as a sparring partner to critically discuss and validate some results and conclusions. 

NOTE: All images used have been either taken from the mini-project statement file or have been created by ourselves (Matlab/Python/Drawio). Only exception is the Mickey Mouse image used in the closed shape question, which is a copyright free to use image found on the internet.
